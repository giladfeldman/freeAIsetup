# MetaScience course: your computer in the browser

Everything is installed: OpenCode with free AI models, R, RStudio, Python, Quarto, Git and Node.js.
Your course folder is **/workspaces/MetaScience**.

**Open the programs** (tap **PORTS** at the bottom of this screen, then the globe icon next to a name):

- **OpenCode (AI assistant)**: port 4096. Choose the folder `/workspaces/MetaScience`.
- **RStudio**: port 8787.

If a tab does not open, allow pop-ups for github.dev, or press and hold the address in PORTS and open it in a new tab.

**Good to know**

- Your work stays here between sessions. Your course files are also in the **MetaScience** folder in the file list on the left. To download a file you hand in: right-click (or press and hold) it there, then **Download**.
- The Codespace switches off by itself after 30 minutes without use. Nothing is lost; open it again from github.com/codespaces.
- First start only: if the setup was still running, open **setup-report.txt** in the course folder to see the result.
